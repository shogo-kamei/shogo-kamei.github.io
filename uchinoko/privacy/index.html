プライバシー ポリシー

きょうのうちの子 - 犬・猫のお世話記録と占い

kamesons（以下「開発者」）は、Android アプリ「きょうのうちの子 - 犬・猫のお世話記録と占い」（以下「本アプリ」）における利用者の情報の扱いを、次のとおり定めます。

1. 本アプリが扱う情報と保存場所

本アプリは、利用者が入力した次の情報を扱います。

  • ペットの名前、種類（犬・猫）、誕生日、犬の体格
  • ペットの写真（利用者が端末の写真から選んだもの）
  • お世話の記録（ごはん・散歩・トイレ・薬と、その日時）
  • 占いを引き直した回数

これらの情報は、お使いの端末の中の、本アプリ専用の保存領域にだけ保存されます。開発者のサーバーや第三者へ送信することはありません。本アプリにはアカウントの登録やログインの機能はなく、開発者が利用者の氏名・メールアドレス・電話番号などを取得することはありません。

写真には、撮影した場所の位置情報などの撮影情報が含まれていることがあります。本アプリは写真を端末の外へ送信しないため、これらの情報が本アプリを通じて外部へ出ることはありません。

2. バックアップと機種変更

本アプリは、Android の自動バックアップ（Google ドライブへの保存）と、機種変更時の端末間のデータ転送を無効にしています。そのため、次のようになります。

  • 本アプリを削除（アンインストール）すると、記録と写真は消え、元に戻せません
  • 機種を変えたときに、記録と写真は新しい端末へ引き継がれません

ただし、端末メーカー独自の移行ツールなど、本アプリの設定に従わない方法で端末全体を複製した場合は、この限りではありません。

3. 広告と、広告のために収集される情報

本アプリは、Google LLC が提供する広告配信サービス「Google AdMob」を利用して広告を表示します。画面の下部に広告を表示するほか、利用者が占いの引き直しを選んだときだけ動画広告を表示します。

AdMob の広告 SDK は、広告の配信・効果の測定・不正の防止のために、次の情報を自動的に収集し、Google に送信します。これらの情報は通信の途中で暗号化されます。

情報内容
IP アドレス端末のおおよその位置の推定に使われることがあります
アプリ内の操作アプリの起動、広告のタップ、動画の視聴など
診断情報アプリと広告 SDK の動作に関する情報（起動時間など）
端末の識別子広告 ID、アプリセット ID など

広告 ID などに基づいて、利用者の興味に合わせた広告が表示されることがあります。広告 ID は、端末の「設定」から再設定・削除できます（設定の項目名は端末によって異なります。例:「設定」→「セキュリティとプライバシー」→「その他のプライバシー設定」→「広告」）。

Google による情報の扱いは、次のページをご覧ください。

  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • Google プライバシー ポリシー

本アプリ自身が外部と通信することはありません。外部との通信は、上記の広告 SDK によるものだけです。

4. 端末の権限

本アプリは、カメラ・位置情報・連絡先・端末のストレージへのアクセスの権限を求めません。写真は、Android の写真選択ツールなどで利用者が選んだ 1 枚だけを読み込みます。

広告の表示のために、広告 SDK が、インターネットへの接続、ネットワークの状態の確認、広告 ID と Android の広告向けの機能（プライバシー サンドボックス）の利用など、広告の表示に必要な権限を使います。

5. 情報の削除

  • ペットを削除すると、そのペットの写真・記録・占いを引き直した回数も一緒に削除されます
  • 本アプリを削除すると、本アプリが保存したすべての情報が削除されます

開発者は利用者の情報を保有していないため、開発者の側で削除する情報はありません。広告 SDK が収集した情報の扱いは、上記の Google のページをご覧ください。

6. 対象年齢

本アプリは、13 歳以上の方を対象としています。13 歳未満の子ども向けのアプリではありません。

7. このポリシーの変更

開発者は、必要に応じてこのポリシーを変更することがあります。変更した場合は、このページに掲載し、改定日を更新します。
